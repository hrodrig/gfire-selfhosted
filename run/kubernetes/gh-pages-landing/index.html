Helm repository · gfire

This site hosts the Helm chart index for deploying gfire on Kubernetes. Published from gfire-selfhosted.

Helm clients fetch index.yaml — a browser is optional.

Add the repo and install

helm repo add gfire https://hrodrig.github.io/gfire-selfhosted
helm repo update
helm install gfire gfire/gfire -n gfire --create-namespace -f my-values.yaml
